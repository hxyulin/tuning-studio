# Tuning Studio 0.1.2

- `studio-server --web` serves the shared UI locally and opens the browser.
- `--elf` and `--chip` start an attach session without resetting or halting the target.
- `--reset` explicitly resets before serving; `--flash` verifies the ELF download and resets.
- Per-launch credentials, exact browser-origin checks and one active browser session protect
  access to local hardware. Closing the tab releases its session and recording.
- Release assets include standalone server archives and SHA-256 checksums for all four hosts.

Hardware flash/reset behavior still requires bench verification. The mock HTTP/WebSocket
integration test checks assets, authentication, ELF loading and session reconnection.
